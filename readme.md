# Biological Learning

Code for [*Dynamical learning in deep asymmetric recurrent neural networks*](https://doi.org/10.1103/lbr6-91sn), D. Badalotti, C. Baldassi, M. Mézard, M. Scardecchia, R. Zecchina (alphabetical order), Phys. Rev. Research **8**, 023281 (2026). arXiv: [2509.05041](https://arxiv.org/abs/2509.05041).

## Installation

### 1. Create and Activate a Virtual Environment

On macOS and Linux:
```bash
python3 -m venv venv
source venv/bin/activate
```

On Windows:
```powershell
python -m venv venv
venv\Scripts\activate
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Install the Package Locally

```bash
pip install -e .
```
